Crop yield prediction is critical for food security and sustainable agriculture. This study develops an AI-powered system using climate data — rainfall, temperature, solar radiation and pesticide usage — to predict crop yield using seven machine learning regression models: Random Forest, SVR, KNN, Decision Tree, XGBoost, LightGBM and CatBoost. CatBoost achieved R²=0.9849. SHAP was applied to interpret model decisions, revealing crop type and rainfall as the most influential predictors. A multi-page Flask web application makes predictions accessible with per-prediction SHAP explanations and AI-driven farming recommendations.
🎯 Objectives
  • Predict crop yield (hg/ha) accurately using climate and agricultural input data
  • Train and compare 7 ML regression models: RF, SVR, KNN, DT, XGBoost, LightGBM, CatBoost
  • Apply SHAP for global and per-prediction feature importance and interpretability
  • Apply LIME for local model-agnostic explanations of individual predictions
  • Evaluate all models with MSE, MAE and R² on identical 80/20 train-test splits
  • Deploy a responsive multi-page Flask web app with real-time prediction and SHAP output
  • Provide AI-driven farming recommendations based on negative SHAP feature contributions
⚙️ Methodology — 5-Stage Pipeline
Stage 1
Data Collection
2,800 real agricultural records. Features: avg_rainfall (mm), pesticides_tonnes, avg_temp (°C), Radiation (MJ/m²), Season, Item/Crop. Target: hg/ha_yield.
Stage 2
Data Preprocessing
Missing value imputation (median/mode). Duplicate removal. Label Encoding for Item and Season columns. StandardScaler normalization. 80/20 train-test split (random_state=42).
Stage 3
EDA & Visualizations
Distribution histograms, box plots, correlation heatmap, season×crop heatmap, actual vs predicted scatter, residual analysis, crop and season yield bar charts.
Stage 4
7 Model Training & Evaluation
Random Forest, SVR, KNN, Decision Tree, XGBoost, LightGBM, CatBoost — all trained on identical splits. MSE, MAE, R² computed. CatBoost selected as best model (R²=0.9849).
Stage 5
SHAP + LIME + Flask Deployment
SHAP TreeExplainer on CatBoost for global and local importance. LIME for model-agnostic per-prediction explanations. Flask multi-page app: Home, Predict, Analytics, Dataset, About.
